## 🔬 Research Value
- **Explainable Quantum Logic**: v5.4.2 introduces "Simple-Word Narratives" that translate complex quantum probability into character-driven reasoning.
- **Why-Not Analysis**: Real-time tracking and explanation of rejected actions, showing the "paths not taken" and the logical reasons for their suppression.
- **Research-Grade Visualizations**: A comprehensive suite of 8+ interactive graphs with deep-dive insights for both technical and non-technical researchers.
- **Counterfactual Replay**: Test "What If" scenarios by simulating how decisions would change under different story tensions.
- **Semantic Narrative Anchoring**: A closed-loop feedback system where character traits and story coherence anchor the quantum reward signal.

## ⚛️ Technical Stack
- **Quantum Core**: PennyLane Variational Quantum Circuits (VQC) with character-trait biasing.
- **Narrative Engine**: Gemini-powered high-fidelity rendering with stylistic consistency.
- **Decision Governance**: Automated rejection logic and influence attribution across multi-agent systems.
- **Research Dashboard**: Elite "Black Edition" Streamlit interface with high-fidelity Plotly telemetry.

## 🚀 Quick Start (Local)

1. **Install Research Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
2. **Configure Environment**:
   Create a `.env` file in the root directory:
   ```env
   GOOGLE_API_KEY=your_gemini_api_key
   ```
3. **Initialize the Lab**:
   ```bash
   streamlit run app.py
   ```
