## 🚀 Quick Start (Local)

1. **Install Research Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
2. **Configure Environment**:
   Create a `.env` file in the root directory:
   ```env
   GOOGLE_API_KEY=your_gemini_api_key
   ```
3. **Initialize the Lab**:
   ```bash
   streamlit run app.py
   ```
